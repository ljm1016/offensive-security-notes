
| Path                         | What is in it        | Why you care                                                              |
| ---------------------------- | -------------------- | ------------------------------------------------------------------------- |
| `/etc/passwd`                | accounts, UID, shell | world readable, first enumeration target                                  |
| `/etc/shadow`                | password hashes      | root only. If you can read it, it is over                                 |
| `/etc/sudoers`               | who can sudo what    | a misconfiguration here is privilege escalation                           |
| `/var/log/`                  | auth.log, syslog     | the record of what happened. Attackers edit it as often as they delete it |
| `/proc/[pid]/`               | per-process state    | credentials leak in `environ` and `cmdline`                               |
| `~/.ssh/`, `~/.bash_history` | keys, typed commands | lateral movement gold                                                     |
## Reading a process from /proc

`/proc` is generated on read. Each process gets a directory named for its PID, and two files in it are worth knowing.
Ex:
```bash
ls -l /proc/2311/cmdline     # the command line again
cat /proc/2311/environ | tr '\0' '\n'
```
