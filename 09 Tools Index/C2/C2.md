
C2 Refers to Command and Control Frameworks which can manage compromised devices to achieve a variety of different goals

They are made up of multiple parts::
- Agents - program generated by the C2 framwork which calls back to a listener on a C2 server
- Listeners - application on the C2 server which waits for callbacks from agents
- Beacon - the process calling back to to the C2 server
- Jitter - ensure that a C2 beacon utilizes a jitter to make traffic harder to distinguish
