
When a regular file has the SUID permission enabled, any user who runs that executable temporarily gains the privileges of the file's owner while the program is running. So if a file owner is root, then the person who runs a file will be granted temp root access.

To find a file SUID binaries:
````
find / -type f -perm -4000 2>/dev/null
````

Ignore these which might result:
Standard system binaries like `passwd`, `sudo`, `su`, `mount`, and `umount` require SUID bits to function normally.

Compare all results to the GTFObins found here: https://gtfobins.org/

When you find an abnormal file (in the below example im using find), use the path to it and then execute a read command on the file that you do not have permissions to read:
```
/usr/bin/find . -exec cat /root/flag.txt \; -quit
```
