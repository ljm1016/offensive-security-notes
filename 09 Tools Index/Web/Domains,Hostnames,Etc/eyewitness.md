#tools-index/web

#### `EyeWitness` screenshots a list of hosts, for fast visual triage when you have too many live hosts to check by hand.

Syntax:
```
eyewitness --web -f hosts.txt -d output_dir
```
Feed it the output of [[httpx]]. Skimming screenshots is much faster than opening each host individually when the list from [[Subdomain Enumeration]] is long.
