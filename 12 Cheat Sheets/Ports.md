#cheatsheets 
Commonly used ports and protocols


| Port      | Protocol   | Description                                    |
| --------- | ---------- | ---------------------------------------------- |
| 21        | FTP        | File sharing                                   |
| 22        | SSH        | Secure shell                                   |
| 80        | HTTP       | Web access                                     |
| 443       | HTTPS      | Secure Web access                              |
| 445       | SMB        | Server message block (share files and devices) |
| 3389      | RDP        | Remote into windows laptops                    |
| 139 + 445 | SMB Beacon | Allows access to restricted network segments   |
|           |            |                                                |
