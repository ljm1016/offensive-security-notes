
List processes actively running executable names:

```
ps -eo pid,ppid,user,comm
```

To see the **full command line**, including every argument a process was started with, ask for `args` instead:

```
ps -eo pid,user,args 
```

View processes and port info:
```
ss -tulpn
```

Each process has an environ folder, to check it:

using 197 as PID example:
```
cat /proc/197/environ tr '\0' '\n'
```
