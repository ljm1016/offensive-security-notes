#networking 

- ARP - address resolution protocol - assigns devices their IP addresses in a network and sends two types of messages
	- ARP Request - asks what is the mac address that owns an IP address
	- ARP Reply - a device only responds if it owns the IP address being asked about which is then stored in an ARP cache for future use
- DHCP - Dynamic Host Configuration Protocol - protocol on a server which is responsible for assigning IP addresses
