#networking 


| VPN Type | Description                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------- |
| PPP      | Used by PPTP for authentication and encryption of data and works using a private key + public cert            |
| PPTP     | Point to Point Tunneling Protocol allows data from PPP to actually leave a network                            |
| IPSec    | Internet Protocol Security encrypts data using the IP framework with strong encryption and high compatibility |
